## About this
Certificate Management Job is a utility module meant to fix the infamous "Cron bug" which causes Let's Encrypt and other certificates to expire. While this is not a real solution to the problem, it works as a temporary fix till the issue will be resolved on the system side.
This bug can be encountered in FreePBX (and similar systems) on version 14, 15, 16, 17 and 18.

<a target="_blank" href="https://community.freepbx.org/t/cron-vs-job-whos-gonna-win/110285">A link to the discussion in FreePBX community regarding this issue</a> (the first post contains links to other discussions regarding the specific problem with Certificate Manager).

PS. If you are interested in CardDAV sync with CNAM and phonebook support for FreePBX, have a look at <a href="https://carddavmiddleware.massi-x.dev">CardDAV Middleware</a>.
